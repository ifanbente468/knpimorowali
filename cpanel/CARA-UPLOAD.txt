KNPI MOROWALI - CARA UPLOAD KE cPANEL
=====================================

Konsep sama seperti paket IUJP: satu zip, upload, extract, selesai.
Beda teknis: KNPI Morowali adalah aplikasi Next.js (Node.js), bukan PHP.
Zip ini berisi HASIL BUILD (.next), jadi server TIDAK perlu menjalankan
`next build` / `npm run build` (server ini kena limit LVE nproc).

PENTING: isi zip diekstrak ke APPLICATION ROOT aplikasi Node,
bukan ke public_html.

  Application root : /home/knph4988/knpi-morowali
  Document root    : /home/knph4988/public_html  (bukan home!)


LANGKAH (UPDATE RUTIN)
----------------------
1. cPanel > Setup Node.js App > app `knpi-morowali` > STOP.
2. File Manager > masuk /home/knph4988/knpi-morowali.
3. Hapus/rename folder `.next` lama (wajib, jangan dicampur).
4. Upload `knpi-cpanel-upload.zip` lalu Extract di folder itu.
5. Pastikan muncul: .next/BUILD_ID, app.js, server.js, prisma/, public/.
6. Setup Node.js App > START (atau Restart).
7. Buka https://knpimorowali.com

Jangan hapus:
  - node_modules/   (dependency Linux sudah terpasang di server)
  - data/           (database knpi.db, uploads, penanda .installed)
  - .env / Environment Variables


PERTAMA KALI DI AKUN BARU
-------------------------
1. Upload zip seperti di atas.
2. Install dependency Linux sekali saja:
   cPanel > Setup Node.js App > tombol "Run NPM Install"
   (atau dari Terminal: npm ci)
3. Environment Variables (pakai path ABSOLUT):
     DATABASE_URL = file:/home/knph4988/knpi-morowali/data/knpi.db
     UPLOAD_DIR   = /home/knph4988/knpi-morowali/data/uploads
     SESSION_SECRET = hasil `openssl rand -hex 32`
     APP_URL      = https://knpimorowali.com
     INSTALL_TOKEN = opsional
4. Start app.
5. Buka https://knpimorowali.com
   -> otomatis redirect ke /install
   -> isi data admin, selesai. /install terkunci otomatis.


BILA MASIH "Index of /" ATAU 500
---------------------------------
- "Index of /" = Document Root domain masih menunjuk home.
  cPanel > Domains > knpimorowali.com > Manage > Document Root = public_html.
- 500 + log "Cannot find package 'bcryptjs-xxxx'":
  build lama dari Turbopack. Pakai zip ini (dibangun dengan --webpack).
- 500 + log Prisma engine:
  DATABASE_URL harus absolut seperti di atas.
- App tidak start:
  cek /home/knph4988/knpi-morowali/stderr.log


MEMBANGUN ULANG ZIP (di komputer, bukan server)
-----------------------------------------------
  powershell -ExecutionPolicy Bypass -File cpanel\build-zip.ps1
  powershell -ExecutionPolicy Bypass -File cpanel\build-zip.ps1 -SkipBuild

Hasil: knpi-cpanel-upload.zip di akar repo.
Skrip memverifikasi: pemisah folder "/", .env/DB tidak ikut, entri wajib ada.


CATATAN KEAMANAN
----------------
- Folder data/ dan .env TIDAK pernah masuk zip.
- Jangan biarkan Document Root = home; isi home bisa terlihat publik.
- Ganti kata sandi admin setelah instalasi pertama.
